Group Members: Rena Simon, Mirian Ventura-Garcia, Ben Layton, Ranvita Kothapalli
Game Name: Last Minute
Instructions: Find clues and solve puzzles to make your way through the dilapidated laboratory. Click on things to move or pick items up! Only one item can be held at a time. You only get one minute each loop before the game resets and you remain with only your knowledge of the previous runs. 

Cheat Codes:
CTRL+R: Resets the game to the title screen
CTRL+L: Add one life
CTRL+O: Unlocks all doors simultaneously
CTRL+T: Add one minute to timer
CTRL+K: Kill enemy

Theme: For our game we implemented the theme by effectively making the game fully reset whenever the time runs out. The game resets to how it was originally except you continue to each loop with your knowledge of the previous, being deducted a life. If you are killed by the alien the game also loops. Once 5 lives have passed it is game over.
